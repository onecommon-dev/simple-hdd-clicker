# Simple HDD Clicker

A very simple hdd clicker for Linux with minimal dependencies. Simulates retro HDD clicking sounds based on disk I/O.

The only requirements are below, which most distros already come with by default:
- Python 3
- Alsa + Pipewire

Execute the script either with 
```
python hddclicker.py
``` 
or
```
chmod +x hddclicker.py
./hddclicker.py
```
